# To-Do List Application

A simple and lightweight task management application built with Python for tracking and organizing your daily tasks.

## Features

- Add, view, update, and delete tasks seamlessly
- Persistent local storage via `task.json`
- Comprehensive unit testing setup using `to_do_list_test.py`

## Project Structure

- `To_do_list.py`: Main application execution script
- `task.json`: Local data store for saving tasks
- `to_do_list_test.py`: Automated unit tests for application logic
- `requirements.txt`: Project dependencies
- `pyproject.toml` & `todo.spec`: Project configuration and build specifications

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Darshan2082002/To_do_list.git](https://github.com/Darshan2082002/To_do_list.git)
   cd To_do_list


  Create and activate a virtual env
  python -m venv .venv
  source .venv/bin/activate  # On Windows use: .venv\Scripts\activate

  Install dependencies
  pip install -r requirements.txt


  Run 
  python To_do_list.py
